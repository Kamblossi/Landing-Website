The project is the frontend for Visual Vortex Studio, a photographer's portfolio website. So far, the landing page has been developed, with plans to expand it with more sections and features in the future.

The core technology stack used in this project includes:

React JS: The primary JavaScript library for building the user interface.

Locomotive Scroll: Used for creating smooth, performant scrolling experiences.

GSAP (GreenSock Animation Platform): Employed for powerful and flexible animations.

Framer Motion: Another animation library, often used for declarative animations and gestures.

Styled Components: For writing CSS directly within JavaScript, enabling component-scoped styling.

The project follows a modular structure, organizing code into components/ for reusable UI elements, sections/ for major page layouts, assets/ for media, and styles/ for styling configurations.
